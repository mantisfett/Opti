# Обзор аналогов и разбор пробелов

Цель — понять, что делают программы этой области, какие приёмы работают, какие нет, и чего не хватает Opti, чтобы заменить набор отдельных утилит. Обзор основан на публичных описаниях функций программ; у большинства из них нет независимых измерений эффекта, поэтому «делает ли это быстрее» в таблице оценивается по доказательствам (см. также `docs/research-latency.md`), а не по обещаниям авторов.

## Классы программ и что в них есть

| Класс | Примеры | Что делают | Что берём | Чего не делаем и почему |
|---|---|---|---|---|
| «Бустеры игр» | Razer Cortex, Wise Game Booster | Закрывают фоновые программы и службы на время игры, «чистят память» | Страница **«Фон»**: замер процессора и памяти по программам, закрытие выбранных | «Очистка памяти» и автоматическое убийство процессов: Windows и так отдаёт память по необходимости, а принудительная очистка заставляет игру подгружать данные заново |
| Управление процессами | Process Lasso, ISLC | Приоритеты, привязка к ядрам, очистка «списка ожидания» памяти | Измерения (DPC/ISR, таймер) и A/B-проверка спорных настроек | Постоянно работающий фоновый «регулятор» и очистка standby-списка: публичных измерений пользы нет, зато есть риск подвисаний |
| Твикеры и сборники скриптов | WinUtil, SophiApp, Winaero Tweaker, Optimizer | Сотни переключателей реестра и служб | Каталог «Твики» с откатом каждой записи; журнал, «Страж», сверка при запуске | Изменения «на всякий случай» без доказательств и без отката; Opti предлагает только то, что можно прочитать, записать и вернуть |
| Приватность | O&O ShutUp10++, Win11Debloat | Отключение телеметрии, рекламы, Copilot, Recall, виджетов | Категория **«Приватность»**: 9 твиков через значения реестра политик (рекламный идентификатор, журнал действий, диагностика, Copilot, Recall, виджеты…) | Удаление системных приложений и блокировка серверов Microsoft через hosts/брандмауэр: ломает обновления, откат неполный |
| Драйверы | Driver Booster, Snappy Driver Installer, DDU, NVCleanstall | Поиск и установка драйверов, чистое удаление | Страница «Драйверы»: возраст и источник, ссылки на официальные страницы производителей | Автоустановка драйверов из сторонних баз: частая причина синих экранов и подмены драйверов вредоносным кодом |
| Снижение пинга | ExitLag, WTFast, NoPing, Mudfish | Игровой трафик идёт через собственные ретрансляторы | Диагностика: задержка до регионов, потери и разброс, **маршрут по узлам**, скорость DNS и смена DNS с откатом | Свои ретрансляторы — это инфраструктура, а не программа; без неё «снижение пинга» невозможно. Opti честно показывает, где теряется время (дома, у провайдера или на дальнем участке) |
| Мониторинг | MSI Afterburner, HWiNFO, CapFrameX | Датчики, оверлей, запись кадровой статистики | Замер кадровой статистики до/после (PresentMon), задержка системы (DPC/ISR), доверительные интервалы | Оверлей поверх игр: античиты считают это внедрением |
| Очистка | CCleaner, BleachBit | Временные файлы, кэши | Страница «Очистка»: список с размерами, только понятные цели | Чистка реестра: пользы нет, риск есть |

## Что даёт доказанный эффект

Измеримо и воспроизводимо: схема питания, частота экрана, игровой режим и планирование GPU (проверяется A/B), разрешение таймера, отключение ускорения мыши (для прицеливания), исправление ошибок конфигурации (память в одном канале, XMP, драйвер дисплея), закрытие тяжёлых фоновых программ, проводное подключение вместо Wi-Fi, быстрый DNS (только вход в игру и поиск матча).

Не подтверждено независимыми измерениями, поэтому не предлагается: Nagle/`TcpAckFrequency`, `NetworkThrottlingIndex`, «оптимизация» адаптера (Interrupt Moderation, EEE, RSS), «очистка памяти», чистка реестра, отключение служб «для скорости».

## Что реализовано в 2.0

- Исправления с откатом, режимы «Максимальная / Баланс / Минимальная», «Страж», A/B-замеры.
- Сеть: регионы, DNS, маршрут, находки по Wi-Fi/Ethernet/«Оптимизации доставки».
- Приватность: 9 твиков с откатом.
- Фон: что грузит ПК, закрытие по кнопке.
- Игровая сессия: закрыть лишнее и схема питания на время игры, с возвратом.
- Пинг: живой монитор, bufferbloat с оценкой A–F.
- Автозагрузка: обратимое отключение лишнего при старте Windows.
- Безопасность: защищённая папка данных, лаунчер без распаковки во `%TEMP%`, удаление с откатом.

## Дорожная карта (пробелы)

1. **Службы и задачи планировщика.** Сознательно отложено: измеримой пользы для FPS и пинга у отключения служб нет (см. `docs/research-latency.md`), а риск есть; возможен короткий белый список ради приватности и поверхности атаки. *(Автозагрузка — готово: страница «Автозагрузка», `opti-cli startup`.)*
2. **Профили игр.** Игровая сессия вручную — готово («Фон» → «Подготовить к игре»). Автоматический запуск и возврат по процессу игры — готово («Настройки»). Приоритет процесса игры — готово (штатный IFEO PerfOptions, без резидентного «регулятора»). Дальше: предпочтение GPU по списку игр.
3. **Драйверы.** Памятка по чистой установке — готово (NVIDIA, AMD, Intel). Сравнение версий с последними у производителя сознательно не делается: стабильного официального API для всех вендоров нет, а запросы к чужим сайтам без вашей команды противоречат принципу «ничего не скачиваем и никуда не ходим сами».
4. **Ввод.** Скорость указателя 6/11 — готово (находка). Выборочная приостановка USB уже входит в «Питание от сети». Частоту опроса мыши Windows не отдаёт, поэтому её Opti не проверяет.
5. **Мониторинг во время игры.** Короткая запись температуры/частот для объяснения троттлинга (без оверлея).
6. **Подпись релиза.** Сертификат подписи кода; пока файлы не подписаны, SmartScreen покажет предупреждение.

Всё из дорожной карты проходит ту же проверку: прочитать → записать → вернуть, и есть ли независимое подтверждение пользы. Если нет — только измерение и объяснение.
