**Opti 1.2.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

## Что нового
- **Новый фирменный стиль**: логотип, иконка, фирменные цвета, баннер на главной.
- **Настройка перед «Исправить автоматически»**: выбор исправлений и теста — полный, быстрый или без теста.
- **Раздел «Драйверы»**: состояние драйверов видео, сети, звука, чипсета, Bluetooth и накопителей со ссылками на официальные сайты.
- **Аудит реестра**: находит вредные «твики» и отключённые обновления и защиту, возвращает стандарт Windows с откатом.
- **Больше очистки**: установщики драйверов, журналы Windows, кеш Discord, Steam, Epic, Spotify, Teams и других браузеров. «Проверьте сами»: «Загрузки» больше 5 ГБ, тяжёлые видео, точки восстановления.
- **Раздел «Твики»**: классическое контекстное меню, быстрые подменю, поиск без Bing, «Завершить задачу» на панели задач и другое — переключателями, с точным откатом.
- **Обновлённый интерфейс**: группы в навигации, плитки-фильтры в анализе, единые компоненты, управление с клавиатуры.
- **Раздел «Программы»**: проверенный софт по категориям — от WizTree до Discord.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML).
