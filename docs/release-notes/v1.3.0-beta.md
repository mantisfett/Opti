**Opti 1.3.0-beta** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае». Происхождение файлов можно проверить: `gh attestation verify Opti.exe --repo mantisfett/Opti`.

## Что нового
- **Три режима вместо пяти целей**: «Максимальная» (вся доказуемая производительность), «Баланс» (рекомендуем) и «Минимальная» (только исправить ошибки). На главной — карточки с описанием и таблица «чем отличаются режимы»; режим можно сменить и на странице исправлений.
- **Новый интерфейс главной**: компактный баннер, крупные карточки режимов, шрифты Segoe UI Variable с настройкой под размер, аккуратная навигация.
- **Защита папки данных**: писать в `C:\ProgramData\Opti` могут только администраторы; подброшенные файлы уходят в карантин.
- **Бережный откат**: настройки, изменённые после Opti, не затираются — Opti сообщит о них.
- **Честнее сравнение**: вердикт по интервалу разности «после − до» с поправкой на число метрик — реальные улучшения видны чаще, ложные — нет.
- **Надёжнее**: один экземпляр программы, защищённая копия для продолжения после перезагрузки, журнал работы, версия схемы журнала отката.

## Совместимость
Старые цели переводятся в режимы автоматически: «Отклик» и «Максимум FPS» → «Максимальная», «Плавность» и «Стрим» → «Баланс», «Тихо» → «Минимальная». Журнал отката прошлых версий обновляется при первом запуске; откат старых изменений работает.

## Бета
Новые части ещё не проверены на большом числе машин. Если что-то работает не так — напишите в Issues, приложив отчёт анализа (HTML) и журнал из `C:\ProgramData\Opti\logs`.
