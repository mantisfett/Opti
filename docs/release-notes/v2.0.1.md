# Opti 2.0.1

Небольшое обновление.

- **Обновление в один клик.** Плашка «Доступна новая версия» → «Скачать» теперь сама скачивает новую версию из релиза GitHub, проверяет её по `SHA256SUMS.txt` (и по подписи, если текущий файл подписан) и заменяет `Opti.exe` на месте. Останется перезапустить программу. В командной строке: `opti-cli update` (`--check` — только проверить).
- **Подпись кода.** Сборка подписывает `Opti.exe` и `opti-cli.exe`, когда в репозитории настроен сертификат (`docs/signing.md`). Самообновление после первого подписанного релиза принимает только файлы с той же подписью.

Обновиться с 2.0.0: скачайте `Opti.exe` ниже (в 2.0.0 ещё нет обновления на месте). Начиная с 2.0.1 обновляться можно из программы.

| Файл | Что это |
|---|---|
| `Opti.exe` | Программа с интерфейсом |
| `opti-cli.exe` | Командная строка |
| `SHA256SUMS.txt` | Контрольные суммы |

Проверка происхождения: `gh attestation verify Opti.exe --repo mantisfett/Opti`.
