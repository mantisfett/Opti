**Opti 2.0** — портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».

## Скачать
| Файл | Что это |
|---|---|
| `Opti.exe` | Программа. Один файл, без установки — просто запустите |
| `opti-cli.exe` | Командная строка для опытных |
| `SHA256SUMS.txt` | Контрольные суммы |

Нужна 64-битная Windows 10/11. Файлы без цифровой подписи, поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае». Происхождение файлов можно проверить: `gh attestation verify Opti.exe --repo allora-dev/optim`.

## Что нового в 2.0
- **Три режима вместо пяти целей**: «Максимальная», «Баланс» (рекомендуем) и «Минимальная» — с описанием и таблицей различий на главной; режим можно сменить на странице исправлений.
- **Новый интерфейс**: компактная главная, карточки режимов, шрифты Segoe UI Variable, единые компоненты.
- **«Страж»**: Opti проверяет, не вернули ли обновления Windows или драйверов его настройки, и применяет их снова по вашему выбору («История» → «На месте ли изменения», `opti-cli verify`).
- **Безопасный запуск**: ничего не распаковывается во временную папку пользователя — приложение выкладывается в защищённую `C:\ProgramData\Opti\app`.
- **Защита данных**: в папку `C:\ProgramData\Opti` пишут только администраторы; подброшенные файлы уходят в карантин.
- **Бережный откат**: настройки, изменённые после Opti, не затираются.
- **Честнее сравнение**: вердикт по интервалу разницы «после − до» с поправкой на число метрик.
- **Удаление в один шаг**: «Настройки» → «Удалить Opti с компьютера» — откат всего и удаление данных.
- **Отчёт о проблеме**: архив с журналами для обращения, никуда не отправляется.
- **English**: the whole interface, command line and report are available in English (automatic by Windows language, or Settings → Interface language).
- **Демо-режим**: `Opti.exe --demo` — посмотреть программу на примере ПК, ничего не меняя.

## Совместимость
Старые цели переводятся в режимы автоматически: «Отклик» и «Максимум FPS» → «Максимальная», «Плавность» и «Стрим» → «Баланс», «Тихо» → «Минимальная». Журнал отката прошлых версий обновляется при первом запуске; откат изменений 1.x работает.

Если что-то работает не так — напишите в Issues, приложив отчёт о проблеме («Настройки» → «Отчёт о проблеме»).
