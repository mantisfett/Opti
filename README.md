# Opti

**Портативная программа для Windows 10/11: находит реальные причины лагов, исправляет только то, что мешает, и честно показывает результат замером «до / после».**

Один файл, без установки. Скачали `Opti.exe` и запустили.

- **Сначала диагноз.** Каждое исправление привязано к найденной проблеме. Никаких «наборов твиков».
- **Только измеримый результат.** «Стало лучше» — только если замер это доказал.
- **Всё откатывается.** Исходные значения пишутся в журнал до изменения. Откат по пункту, по сессии или целиком.
- **Честно про железо.** Перегрев, HDD, мало памяти, Wi-Fi — программа так и скажет.
- **Рекомендации с источниками.** Ссылки на Microsoft, Intel, AMD, OBS — а не «говорят, что помогает».

> **Статус: 2.0.0.** Логика покрыта 190+ автоматическими тестами; тесты и сборка проходят в CI на Windows и Linux, снимки всех страниц делаются в каждом PR. Новые части 2.0 (лаунчер, «Страж», удаление) ещё не проверены на большом числе машин — пишите, если что-то работает не так.

Нужна 64-битная Windows 10 или 11. Программа просит права администратора: без них не прочитать события ядра и не поменять системные настройки. Файлы пока без цифровой подписи (сборка к ней подготовлена: [docs/signing.md](docs/signing.md)), поэтому SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае»; происхождение файла можно проверить: `gh attestation verify Opti.exe --repo mantisfett/Opti`.

Первый запуск новой версии чуть дольше (несколько секунд): программа выкладывает себя в защищённую папку `C:\ProgramData\Opti\app` (около 150 МБ; хранятся текущая и одна предыдущая версия) и дальше запускается оттуда. Во временную папку пользователя ничего не распаковывается.

## Как пользоваться

1. **Главная.** Выберите режим — «Максимальная», «Баланс» или «Минимальная» (см. ниже) — и нажмите «Проанализировать». 30–60 секунд, только чтение.
2. **Результаты анализа.** Что найдено, почему это важно, на каких данных основан вывод и ссылка на источник.
3. **«Исправить автоматически».** Сначала короткая настройка: отметьте нужные исправления и выберите тест — **полный** (около 2 минут), **быстрый** (2 × 20 с) или **без теста** (только применить; эффект тогда не доказан). Число и длительность прогонов можно поменять. Дальше Opti всё сделает сам: тест → исправления (с точкой восстановления) → перезагрузка, если нужна (после входа программа продолжит сама) → повторный тест → результат.
4. **Результат.** Было → стало с 95 % доверительными интервалами, графики фреймтайма. Каждое исправление можно откатить отдельно.
5. **«Страж».** Обновления Windows и драйверов иногда возвращают настройки — частоту экрана, схему питания, ключи реестра. При запуске Opti сверяет журнал с системой и подскажет; в «Истории» → «На месте ли изменения» возвращённое можно применить снова одной кнопкой (откат по-прежнему вернёт значение до Opti).

**Язык.** Интерфейс, командная строка и отчёты есть на русском и английском. По умолчанию язык берётся из Windows (русский — для русскоязычных, остальным — английский); выбрать можно в «Настройках» → «Язык интерфейса» (после перезапуска) или ключом `--lang ru|en` (`Opti.exe --demo --lang en`). Тексты хранятся в `src/Opti.Core/Localization/en/*.json` (ключ — русская строка); `python3 build/loc-extract.py` показывает, чего не хватает, а тест следит, что в английском интерфейсе не осталось русского.

Хотите сначала посмотреть, ничего не меняя? `Opti.exe --demo` открывает программу на примере настольного ПК: анализ, исправления, замеры и откат работают на эмуляции, система не трогается.

Можно и вручную: «Выбрать исправления вручную» → замер → галочки → применение. Спорные настройки (HAGS, таймеры) проверяются A/B-замером: остаётся только вариант с доказанным улучшением.

### Режимы

Во всех режимах Opti сначала ищет проблемы и меняет только то, что нашёл. Режим решает, что из найденного будет **отмечено по умолчанию**; перед применением галочки можно поменять, режим — переключить прямо на странице «Исправления».

- **Максимальная** — вся производительность, которую можно доказать. Всё из «Баланса» плюс процессор без энергосбережения в фоне (Power Throttling) и мышь без ускорения. Для игрового ПК от сети; на ноутбуке — выше нагрев и расход батареи.
- **Баланс** — рекомендуем для большинства. Исправление ошибок плюс питание от сети без ограничений, без фоновой записи Game Bar и энергосбережения сетевой карты, таймеры и HAGS с A/B-замером. Привычное поведение (мышь) не трогает.
- **Минимальная** — только исправить ошибки: частота экрана, видеокарта для игр, игровой режим, OBS, файл подкачки, стандартные значения Windows после «оптимизаторов». Питание, сеть, таймеры и мышь не трогает, A/B-замеров нет.

| Что делает Opti | Максимальная | Баланс | Минимальная |
|---|:---:|:---:|:---:|
| Исправление найденных ошибок: частота экрана, видеокарта, OBS, файл подкачки | ✓ | ✓ | ✓ |
| Возврат стандартных значений Windows после «оптимизаторов» | ✓ | ✓ | ✓ |
| Питание от сети без энергосберегающих ограничений | ✓ | ✓ | — |
| Без фоновой записи Game Bar и энергосбережения сетевой карты | ✓ | ✓ | — |
| Таймеры и HAGS — только если A/B-замер докажет пользу | ✓ | ✓ | — |
| Процессор не экономит энергию в фоне (Power Throttling) | ✓ | — | — |
| Без ускорения мыши | ✓ | — | — |
| Нагрев, шум и расход батареи | выше | чуть выше | как было |

Предупреждения о железе и ссылки на драйверы показываются во всех режимах — сами они ничего не меняют.

**Драйверы** — все важные драйверы (видео, сеть, звук, чипсет, Bluetooth, накопители) с состоянием: в порядке, старый, стандартный драйвер Microsoft вместо драйвера производителя или драйвера нет. У каждого — ссылка на официальный сайт: NVIDIA, AMD, Intel, Samsung или сайт производителя ноутбука или материнской платы (ASUS, MSI, GIGABYTE, ASRock, Acer, Lenovo, HP, Dell…). Opti сам драйверы не скачивает.

**Очистка** — отдельный раздел: корзина, временные файлы, загруженные обновления Windows, кеш оптимизации доставки, отчёты об ошибках, распакованные установщики драйверов (`C:\NVIDIA`, `C:\AMD`), журналы обслуживания Windows, по желанию — кеш миниатюр, шейдеров, браузеров (Chrome, Edge, Brave, Яндекс, Opera, Vivaldi, Firefox), кеш Discord / Steam / Epic / Spotify / Teams, дампы. Только старые файлы, занятые пропускаются, по ссылкам (symlink/junction) программа не ходит, документы и реестр не трогает.

Отдельно — **«Проверьте сами»**: Opti ничего не удаляет, но показывает, где много места: «Загрузки» (рекомендация разобрать, если больше 5 ГБ), тяжёлые видео больше 1 ГБ (записи игр и фильмы — список со ссылками «показать в Проводнике»), точки восстановления (размер и переход в «Защиту системы»), `Windows.old`.

**Твики** — изменения, которые видно сразу, каждое включается и выключается переключателем (выключение возвращает ровно то, что было до Opti): полное контекстное меню как в Windows 10, быстрое открытие подменю, расширения файлов, Проводник на «Этот компьютер», поиск в «Пуске» без Bing, «Завершить задачу» на панели задач, без рекламы и автоустановки приложений, значки панели задач слева, мгновенное сворачивание окон, автозагрузка без паузы, отключение «Быстрого запуска». На FPS не влияют — это про удобство, поэтому в «Исправить автоматически» не входят.

**Программы** — рекомендуемый софт по категориям (диск, мониторинг, драйверы, общение, стрим, игры, системные компоненты, утилиты, браузеры) — только ссылки на официальные сайты: WizTree, CrystalDiskInfo, HWiNFO, LatencyMon, DDU, Discord, OBS, 7-Zip и другие.

Интерфейс следует теме Windows (светлая или тёмная) в фирменных цветах Opti.

## Исправления

23 исправления, каждое с откатом: частота экрана, привязка игр к GPU, оптимизация оконных игр и VRR, игровой режим, фоновая запись Game Bar, MPO, HAGS (A/B), схема питания, параметры питания от сети, Power Throttling, таймеры BCD, глобальное разрешение таймера (A/B), OBS (захват игры, без администратора), автозагрузка (только выбранное), энергосбережение сетевого адаптера, ускорение мыши, горячие клавиши залипания, файл подкачки, стандартные значения реестра после «оптимизаторов», включение обновлений и защиты Windows, «Оптимизация доставки» только в локальной сети, быстрый DNS (по вашему выбору на странице «Сеть»).

Чего Opti не делает: «чистка реестра» (удаление «мусорных» ключей — пользы нет, риск есть; Opti только возвращает стандарт там, где «твик» доказанно вредит), «ускорители ОЗУ», массовое отключение служб, `LargeSystemCache`, «сетевые твики» без доказанного эффекта.

## Сеть и пинг

Страница **«Сеть»** (и `opti-cli net --regions --dns`) — только измерения:
- **Задержка до регионов.** Время TCP-соединения, разброс и потери до облачных регионов, где часто стоят игровые серверы: видно, куда связь ближе и стабильнее, и нет ли потерь и скачков (Wi-Fi, кабель, провайдер). Игровые серверы не опрашиваются.
- **Скорость DNS.** Сравнение вашего DNS с Cloudflare, Google, Quad9 и AdGuard. Быстрый DNS ускоряет вход в игру и поиск матча; на пинг идущего матча он не влияет, и Opti так и пишет. Смена DNS — по кнопке, с откатом на прежние серверы или автоматический режим.

- **Wi-Fi: каналы** (и `opti-cli net --wifi`). Сколько соседних сетей мешает на вашем канале (2,4 ГГц: каналы 1–13 перекрываются, чистые — 1, 6, 11; 5 ГГц: мешают только сети на том же канале), какой канал свободнее и стоит ли перейти на 5 ГГц. Рекомендуются только каналы без радаров (не 52–144): при радарах роутер переключает канал, и связь обрывается. Свои точки доступа (тот же SSID) помехой не считаются. Список сетей берётся из `netsh`; если Windows его не отдаёт, включите «Службы геолокации».
- **Задержки системы** (страница «Задержки», `opti-cli latency`): какие драйверы надолго занимают процессор на уровне ядра (DPC/ISR) и насколько точен таймер — причина микрофризов, треска звука и «ватной» мыши. Только чтение событий ядра (нужны права администратора). До 0,5 мс — норма, больше 1 мс — повод обновить или отключить устройство.
- **Кто грузит сеть.** Замер на 15 секунд: сколько каждая программа отдаёт и качает (по событиям ядра Windows, TCP и UDP; видны только объёмы, не содержимое; нужны права администратора). Фоновая загрузка и отдача — частая причина скачков пинга: программу можно закрыть прямо отсюда (системные процессы защищены). Замер использует ту же сессию ядра, что и тест задержек, поэтому два замера одновременно не запускаются — Opti скажет об этом.
- **Живой пинг.** Пинг каждые полсекунды до выбранного сервера: график, среднее, лучшее, худшее, разброс, потери. Запустите, сверните Opti, поиграйте — и посмотрите, были ли скачки. Останавливается при уходе со страницы.
- **Пинг под нагрузкой (bufferbloat).** Пинг в простое, под скачиванием и под отдачей, оценка A–F по росту пинга (до 30 мс — A, до 60 — B, до 200 — C, до 400 — D, больше — F). Частая причина «лагов, когда кто-то качает»; лечится на роутере (SQM / Smart Queue), и Opti так и пишет. На время проверки качаются тестовые данные с speed.cloudflare.com.
- **Маршрут до сервера.** Трассировка по узлам (ICMP): где теряется время — дома (роутер, Wi-Fi), у провайдера или на дальнем участке, и есть ли потери на конечном узле. Узлы, не отвечающие на служебные пакеты, — норма и проблемой не считаются.

Анализ дополнительно находит то, что реально мешает пингу: «Оптимизация доставки» в режиме «интернет» (Windows раздаёт обновления чужим ПК и забивает исходящий канал), проводное подключение на 100 Мбит/с и ниже (кабель, разъём), слабый сигнал Wi-Fi, режим питания сетевой карты, bufferbloat.

## Автозагрузка, фон и приватность

- Страница **«Автозагрузка»** (и `opti-cli startup`) — что запускается вместе с Windows: ключи Run (пользователь, все пользователи, 32-бит) и папки «Автозагрузка». Включение и отключение — значением StartupApproved, как в «Диспетчере задач»: программы не удаляются, ярлыки и ключи не трогаются. Магазины игр, мессенджеры, облака и «обновлялки» помечены «можно отключить» (кнопка «Отключить рекомендуемые»); защита, драйверы устройств и сам Opti заблокированы. Каждое изменение пишется в журнал и откатывается в «Истории». Время загрузки Opti не измеряет и не обещает.

- **Игровая сессия** (страница «Фон»): кнопка «Подготовить к игре» закрывает отмеченные программы (по умолчанию — браузеры, облачную синхронизацию, обновлялки, плееры; мессенджеры, магазины игр и запись не отмечены: им нужны голос, запуск и клипы) и на время игры включает схему питания «Высокая производительность»; «Завершить сессию» возвращает прежнюю схему. Схема идёт через журнал; на ноутбуке и при работе от батареи не меняется. Закрытые программы Opti обратно не запускает.
- **Автоматическая игровая сессия** («Настройки»): укажите имена процессов игр, и пока игра запущена, включена схема «Высокая производительность»; после закрытия игры схема возвращается. Программы автоматически не закрываются. Сессию, начатую вручную, наблюдатель не трогает; на ноутбуке схема не меняется.
- **Высокий приоритет игр** («Настройки», для игр из того же списка): значение `CpuPriorityClass = 3` в `Image File Execution Options\<игра>.exe\PerfOptions` — штатный механизм Windows, который выставляет приоритет при запуске игры без фоновой программы-регулятора. Идёт через журнал, откатывается, проверяется «Стражем». Эффект зависит от игры (Windows и так поднимает приоритет активного окна), поэтому Opti не обещает прироста — проверяйте замером «до / после».
- Страница **«Фон»** — короткий замер процессора и памяти по программам (браузер, мессенджеры, магазины игр, облачная синхронизация, утилиты устройств). Закрыть программу можно по кнопке; системные процессы, службы и сам Opti защищены и не показываются. Ничего не отключается навсегда.
- Категория **«Приватность»** в «Твиках»: рекламный идентификатор, персонализация, журнал действий, объём диагностики, запросы отзывов, онлайн-распознавание речи, Copilot, Recall, виджеты. Это значения реестра политик с откатом через журнал, без удаления системных приложений.

Сравнение с другими программами этой области и план развития — `docs/research-competitors.md`.

### Чего Opti сознательно не делает
В «оптимизаторах» много советов без измеримого эффекта. Opti их не включает и не предлагает, а спорное проверяет A/B-замером:
- **Nagle / TcpAckFrequency / TCPNoDelay.** Влияют только на TCP; большинство игр общается по UDP. Заметной пользы в независимых замерах нет.
- **NetworkThrottlingIndex, SystemResponsiveness (MMCSS).** Значения из гайдов не подтверждены тестами; разница в бенчмарках — в пределах шума, возможны задержки при переключении задач.
- **Отключение прерываний-модерации, EEE, RSS-очередей и «буферов» сетевой карты.** В документации Microsoft и Intel это компромисс между загрузкой процессора и задержкой, а не гарантированный выигрыш; результат зависит от карты.
- **«Ускорители ОЗУ», отключение служб пачками, чистка реестра.** Вреда больше, чем пользы.
Источники и обоснование — в `docs/research-latency.md`.

## Честное сравнение

- Метрики: средний FPS, 1 % и 0,1 % low, фреймтайм — медиана, p95, p99, разброс.
- Прогрев отбрасывается. Несколько прогонов. 95 % ДИ — блочный бутстреп (блоки ~1 с).
- «Лучше» или «хуже» — только если 95 % интервал **разности** «после − до» не содержит ноль **и** разница больше разброса между прогонами. Для трёх ключевых метрик (средний FPS, 1 % low, p99) интервал шире — 98,3 % (поправка Бонферрони), потому что общий вердикт смотрит на любую из них.
- Прогоны с троттлингом исключаются. Разные условия (разрешение, экран, питание) помечают сравнение как ненадёжное.

## Безопасность

- Исходное значение пишется в журнал (`C:\ProgramData\Opti\journal.db`) **до** изменения. Не удалось сохранить — изменение не выполняется. Запись подтверждается после изменения; если программа завершилась посередине, запись помечается «не подтверждено», откат всё равно возможен.
- Откат не затирает то, что поменяли **после** Opti (вы сами, Windows или другая программа): такая настройка остаётся как есть, и Opti об этом сообщает. Вернуть исходное принудительно — `opti-cli rollback … --force`.
- Папка данных защищена: писать в `C:\ProgramData\Opti` могут только администраторы. Папка или файлы, созданные в ней обычным пользователем (например, подброшенный `settings.json`), переносятся в карантин `Opti.untrusted-<дата>` и не используются.
- Задача продолжения после перезагрузки запускает программу из защищённой папки данных, а не файл из «Загрузок».
- Одновременно работает только один экземпляр Opti (окно или команда, меняющая систему).
- Если права администратора выданы паролем другой учётной записи, Opti предупредит: настройки пользователя применятся к той учётной записи.
- Журнал работы — `C:\ProgramData\Opti\logs` (14 дней); в нём нет личных данных, только что и когда изменено. «Настройки» → «Отчёт о проблеме» (или `opti-cli bugreport`) собирает журнал, сессии и журнал изменений в архив на рабочем столе; имя пользователя в путях скрыто, архив никуда не отправляется.
- Перед первым применением — точка восстановления Windows.
- В игры ничего не внедряется (ETW только читает события), античиты не реагируют.
- Телеметрии нет. Сеть — только для проверки обновлений (выключается) и теста сети по вашей команде.
- Удалить Opti: «Настройки» → «Удалить Opti с компьютера» (или `opti-cli uninstall`) — откат всех изменений, удаление задачи продолжения и папки данных; затем удалите `Opti.exe`. Если что-то откатить не удалось, папка данных остаётся — без журнала изменения уже не вернуть.
- Данные GameTune 1.0.0-beta переносятся автоматически, откат старых изменений работает. Журнал прошлых версий обновляется автоматически; журнал более новой версии старая программа не откроет.
- Релизные файлы подписаны аттестацией происхождения GitHub: `gh attestation verify Opti.exe --repo mantisfett/Opti` покажет, что файл собран из этого репозитория.
- Безопасный запуск: `Opti.exe` из релиза — лаунчер без нативных библиотек, он ничего не распаковывает во временную папку пользователя (её может изменить любая программа этого пользователя, а Opti работает с правами администратора). Приложение выкладывается в `C:\ProgramData\Opti\app\<версия>-<хеш>`, куда пишут только администраторы; распаковка атомарная — прерванная не считается готовой.

## Командная строка

```bash
opti-cli doctor
```

```bash
opti-cli run --goal balanced --mode synthetic
```

Проверить, на месте ли изменения: `opti-cli verify` (`--reapply` — применить снова возвращённое Windows). Режимы: `--goal max`, `--goal balanced` (по умолчанию), `--goal min`; старые цели (`latency`, `smooth`, `fps`, `stream`, `quiet`) тоже принимаются. `opti-cli plan --goal min` — сухой прогон: точный список изменений без применения.

Команды `run`, `resume`, `analyze`, `plan`, `measure`, `apply`, `ab`, `compare`, `report`, `rollback`, `verify`, `history`, `latency`, `net`, `version`, `doctor`, `bugreport`, `uninstall` описаны в `opti-cli help`.

## Сборка из исходников

Нужен .NET 10 SDK. Всё, кроме запуска интерфейса и ETW, собирается и тестируется и в Linux.

```bash
dotnet test
```

```bash
build/publish.sh
```

Снимки всех страниц на демо-данных (светлая и тёмная тема): в Windows — `Opti.exe --screenshots <папка>`, в Linux — `build/screenshots-wine.sh` (WPF под Wine, подменные шрифты — для проверки вёрстки). В CI снимки выкладываются артефактом `screenshots`.

CI (`.github/workflows/ci.yml`) собирает и тестирует на Linux и Windows; предупреждения компилятора и анализаторов — ошибки сборки. Релиз собирает GitHub Actions (`.github/workflows/release.yml`): пуш в ветку `release` → тесты на Windows → портативная сборка → аттестация происхождения → релиз с тегом `v<версия>`. Сторонние действия закреплены по SHA коммита.

