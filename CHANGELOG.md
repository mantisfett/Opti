# Изменения

## 2.0.0

**Безопасный запуск.** `Opti.exe` и `opti-cli.exe` из релиза — лаунчер (`src/Opti.Launcher`): один управляемый файл без нативных библиотек, который ничего не распаковывает во временную папку пользователя. Приложение встроено zip-ресурсом и выкладывается в защищённую `C:\ProgramData\Opti\app\<версия>-<хеш>` (атомарно: распаковка во временную соседнюю папку, метка готовности последней, переименование); хранятся текущая и одна предыдущая версия. Задача продолжения запускает программу оттуда же.

**«Страж».** Сверка действующих изменений из журнала с системой: на месте / возвращено Windows или драйвером / изменено после Opti. Проверка при запуске (отключается в настройках), блок в «Истории» с повторным применением, `opti-cli verify [--reapply] [--all]`. Повторное применение пишется в журнал как обычное изменение — откат возвращает значение до Opti.

**Удаление.** «Настройки» → «Удалить Opti с компьютера» и `opti-cli uninstall`: откат всего, задача продолжения, папка данных (если откат прошёл без ошибок).

**Снимки интерфейса.** `Opti.exe --screenshots <папка>` рисует все страницы на демо-данных в светлой и тёмной теме; CI-джоб `screenshots` выкладывает их в каждом PR, `build/screenshots-wine.sh` делает то же в Linux. По снимкам исправлены обрезанный текст в карточках режимов и перегруженные интервалы на странице сравнения.

**Сеть и пинг.** Страница «Сеть» и `opti-cli net --regions --dns`: задержка, разброс и потери до облачных регионов (TCP-рукопожатие), скорость DNS (UDP-запросы) и смена DNS по кнопке с откатом. Новые находки: «Оптимизация доставки» в режиме «интернет», проводное подключение ≤ 100 Мбит/с, слабый сигнал Wi-Fi. Новые исправления: `DELIVERY_OPT_LAN`, `DNS_SET`. Исследование — `docs/research-latency.md`; чего Opti сознательно не делает (Nagle, MMCSS-твики, TCP-«оптимизации») — в README.

**Английский язык.** Весь интерфейс, командная строка (справка, сообщения) и HTML-отчёт переведены. Язык по Windows или выбор в настройках, `--lang`. Слой перевода `Loc` (русские строки — ключи; шаблоны для строк с подстановками), перевод XAML при показе, переводы в `Localization/en/*.json`, тесты полноты (XAML, находки всех профилей, исправления, твики, программы, демо-путь), `build/loc-extract.py`. Снимки: `OPTI_LANG=en build/screenshots-wine.sh`.

**Демо-режим.** `Opti.exe --demo` — настоящий интерфейс на примере настольного ПК (драйверы, очистка, замеры, «Страж»); всё работает на эмуляции, система не меняется.

**Прочее.** Журнал отката освобождает файл, если не открылся (найдено CI на Windows). Командная строка разбита по файлам. Демо-окружение (`DemoAppServices`) для снимков и тестов.

## 1.3.0-beta

**Три режима вместо пяти целей.** «Максимальная» — всё, что даёт прирост (в том числе Power Throttling и ускорение мыши); «Баланс» — исправление ошибок плюс питание, сеть и игровые параметры Windows (по умолчанию); «Минимальная» — только исправление ошибок и возврат стандартных значений Windows, без A/B-замеров. Режимы вложены друг в друга (проверяется тестом). Неотмеченные исправления остаются в плане — их можно выбрать вручную; режим переключается на странице «Исправления». Каждое исправление помечено: исправление ошибки, настройка под производительность или изменение привычек. Старые цели в настройках, сессиях и командной строке переводятся в режимы автоматически.

**Главная.** Карточки режимов с пунктами «что входит», индикатором глубины изменений, нагревом и способом проверки; таблица «Чем отличаются режимы». Баннер стал компактным (его растягивала декоративная подсветка), «Результат» больше не подсвечивается вместе с «Главной».

**Шрифты и стили.** Шкала Fluent (12 / 14 / 18 / 20 / 28): Segoe UI Variable Display для заголовков, Text для текста, Small для подписей; чёткий рендеринг мелкого текста, плитки значков, единые радиусы, аккуратная рамка фокуса в навигации, сегментированный переключатель режима.

**Безопасность.** Папка данных получает явные права (Администраторы и SYSTEM — полный доступ, Пользователи — чтение); папка или файлы, созданные обычным пользователем, переносятся в карантин. Задача продолжения запускает защищённую копию программы. Один экземпляр Opti. Предупреждение, если права администратора выданы паролем другой учётной записи.

**Журнал отката.** Версия схемы (обновление старых журналов, отказ открывать журнал более новой версии), подтверждение каждой записи после изменения, ожидание блокировки вместо ошибки. Откат не затирает настройки, изменённые после Opti (`rollback --force` — принудительно).

**Сравнение.** Вердикт по бутстреп-интервалу разности «после − до»; для ключевых метрик — поправка Бонферрони. Интервал разности показан в интерфейсе, отчёте и командной строке.

**Прочее.** «Отчёт о проблеме» (кнопка в настройках и `opti-cli bugreport`) — архив для обращения, никуда не отправляется. Журнал работы в `C:\ProgramData\Opti\logs`; сравнение версий по SemVer (`beta.2` < `beta.10` < `rc.1`); CI на Linux и Windows, предупреждения — ошибки сборки, покрытие тестами, действия закреплены по SHA, аттестация происхождения релизов.

## 1.2.0-beta

**Фирменный стиль.** Новый логотип и иконка, фирменные цвета (синий → бирюзовый) вместо системного акцента, баннер на главной, новая боковая панель.

**«Исправить автоматически» с настройкой.** Перед запуском можно отметить исправления и выбрать тест: полный, быстрый (2 × 20 с) или без теста. Число и длительность прогонов настраиваются; замер «после» повторяет выбранные параметры.

**Драйверы.** Новый раздел и проверка: видео, сеть, звук, чипсет, Bluetooth, накопители. Старые (видео — старше 18 месяцев, остальное — старше 3 лет) и стандартные драйверы Microsoft вместо драйверов производителя. Ссылки на официальные сайты NVIDIA, AMD, Intel, Samsung и производителей ноутбуков и материнских плат.

**Аудит реестра.** 16 правил: вредные «твики» производительности (LargeSystemCache, TdrLevel, TdrDelay, SysMain, Prefetch, Win32PrioritySeparation, ClearPageFileAtShutdown, DisablePagingExecutive) и отключённые обновления и защита (политики Центра обновления, службы wuauserv / BITS / Audiosrv, Defender, защиты от Spectre). Два новых исправления возвращают стандарт Windows с откатом; на модифицированных сборках они не отмечены по умолчанию.

**Очистка.** Новые категории: распакованные установщики драйверов, журналы обслуживания Windows, кеш Discord / Steam / Epic / Spotify / Teams, кеш Яндекс Браузера, Opera, Vivaldi, дампы сбоев программ. Раздел «Проверьте сами»: «Загрузки» больше 5 ГБ, тяжёлые видео со ссылками «показать в Проводнике», точки восстановления, Windows.old. Кнопка «Очистить» всегда видна внизу.

**Программы.** Рекомендуемый софт по категориям — только официальные сайты.

**Твики.** Новый раздел из 11 твиков удобства с переключателями: классическое контекстное меню, быстрые подменю, расширения файлов, Проводник на «Этот компьютер», поиск без Bing, «Завершить задачу» на панели задач, без рекламы и автоустановки приложений, панель задач слева, мгновенное сворачивание окон, автозагрузка без паузы, отключение «Быстрого запуска». Выключение откатывает изменение по журналу; кнопка «Перезапустить Проводник».

**Интерфейс.** Единые компоненты (плашки, подсказки, переключатели, плитки-сводки, пустые состояния), общие отступы на всех страницах, видимая рамка фокуса для управления с клавиатуры. Навигация разбита на группы «Оптимизация» и «Инструменты», «История» и «Настройки» — внизу; у недоступных пунктов подсказка, когда они появятся. В анализе — плитки «критично / важно / советов / исправит Opti», которые фильтруют список.


## 1.1.0-beta — Opti

**Новое имя.** GameTune теперь называется Opti. Данные 1.0.0-beta (журнал отката, история) переносятся автоматически, откат старых изменений работает.

**Портативность.** Один файл `Opti.exe` без установки; синтетический тест встроен в него. Установщик убран.

**Интерфейс.** Новый дизайн на системной теме Fluent: светлая/тёмная тема и акцентный цвет Windows, значки Segoe Fluent, минимум оформления.

**«Исправить автоматически».** Тест → рекомендованные исправления → перезагрузка (если нужна, продолжение само) → тест → результат.

**Замер.** Синтетический тест по умолчанию (30 с на прогон, около 2 минут), «Своя игра» — по желанию. Режим PresentMon убран из интерфейса (остался в командной строке).

**Очистка.** Корзина, временные файлы, загруженные обновления, кеш оптимизации доставки, отчёты об ошибках, кеш миниатюр, шейдеров и браузеров, дампы. Бережно: только старые файлы, по ссылкам не ходит, занятые пропускает.

**Новые проверки.** Монитор в материнской плате, видеокарта без драйвера, устройства без драйверов, чек-лист после переустановки Windows, драйвер чипсета для Ryzen X3D, Intel с P/E-ядрами на Windows 10, ожидающая перезагрузка, отключённый файл подкачки, ускорение мыши, горячие клавиши залипания.

**Новые исправления.** Отключение ускорения мыши, отключение горячих клавиш залипания, файл подкачки по умолчанию.

**Рекомендации с источниками.** Ссылки на страницы Microsoft, Intel, AMD, OBS у каждой рекомендации.

**Исправлено.** Ложный «троттлинг» на видеокартах NVIDIA («Not Active» распознавалось как «Active»), из-за которого прогоны помечались ненадёжными. Определение системного диска. Структура корзины для x64.

**Платформа.** .NET 10 (LTS); SQLite с исправлением уязвимости GHSA-2m69-gcr7-jv3q.


## 1.0.0-beta — первая публичная версия

**Анализ (§3).** 14 коллекторов: устройство, Windows и модифицированные сборки (ReviOS, AtlasOS и др.), CPU, все GPU через DXGI, гибридная графика и MUX, экраны (частота, встроенный ли, HDR), ОЗУ (XMP/EXPO, каналы, главные потребители), диски (тип, здоровье, износ, TRIM), температуры (ACPI, nvidia-smi), питание (схема, режим Windows, Modern Standby), таймеры BCD, VBS/HVCI/BitLocker, HAGS/MPO/Game Mode/DVR, автозагрузка, оверлеи, OBS (сцены, буфер повтора, запуск от администратора), сеть, игры Steam/Epic/GOG/Xbox с привязкой к GPU. 27 детекторов — все правила таблицы §3.2 и ещё 7.

**Стратегия (§4).** Класс устройства, 5 целей, явные конфликты целей, уровни риска, порядок «сначала бесплатное и безопасное», исключения в настройках, учёт BitLocker и модифицированных сборок.

**Исправления (§5).** 16 исправлений. Исходное значение пишется в журнал (SQLite) до изменения и фиксируется один раз. Каждое исправление атомарно. Точка восстановления. Откат по исправлению, по сессии или полный. Резервные копии файлов. Сухой прогон.

**Замеры (§6).** ETW-сбор кадров, PresentMon (режим вывода, задержка), синтетический тест D3D11, тест DPC/ISR, точность таймера, пинг и bufferbloat. Несколько прогонов, отброс прогрева, блочный бутстреп с 95 % ДИ, вердикт «лучше / шум / хуже», контроль троттлинга и условий.

**Сценарий (§2).** Сессии с продолжением после перезагрузки (задача планировщика при входе), самопроверка после перезагрузки (применилось ли, синие экраны), автоматическая A/B-проверка спорных настроек с откатом, если нет достоверного улучшения.

**Интерфейс (§8).** WPF: главная, отчёт анализа, замеры с живым графиком, стратегия с галочками, применение, сравнение с графиками и откатом по пункту, история, настройки. Консольная версия `gametune-cli` с мастером `run`.

**Отчёты.** Самодостаточный HTML со SVG-графиками (светлая и тёмная тема), CSV с сырыми фреймтаймами.

**Выпуск (§10).** Установщик (NSIS), портативный zip, проверка обновлений через GitHub Releases (только уведомление), без телеметрии.

### Известные ограничения бета-версии
- Код, работающий с Windows, проверен автоматическими тестами на эмуляции профилей, но в этой версии не проходил проверку на реальных машинах (§11). Первый запуск лучше сделать в виртуальной машине или после создания точки восстановления.
- Файлы не подписаны цифровой подписью — Windows SmartScreen покажет предупреждение.
- Профили NVIDIA/AMD через NVAPI/ADLX — в следующей версии (по ТЗ — версия 2).
